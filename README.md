Customer Shopping Behavior Analysis

📌 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, customer preferences, spending trends, and factors that influence customer purchasing decisions.

The project demonstrates an end-to-end data analytics workflow using SQL, Python, and Power BI, starting from raw customer shopping data and progressing through data analysis and business insights.

🎯 Business Objective

The main objective of this project is to understand customer purchasing behavior and generate actionable insights that can help businesses:

* Understand customer demographics and purchasing patterns
* Identify high-value customer segments
* Analyze spending behavior
* Understand product and category preferences
* Examine the impact of discounts, reviews, and other factors on purchases
* Support data-driven marketing and business decisions

🛠️ Tools & Technologies

* SQL — Data querying and business analysis
* Python — Data analysis and exploration
* Pandas — Data manipulation
* NumPy — Numerical analysis
* Power BI — Data visualization and dashboarding
* Microsoft Excel / CSV — Dataset handling
